# 実装計画（Implementation Plan）

## 1. 実装方針

本アプリケーションは、WinAPIとC言語を用いてGUIで動作する日本語単語学習ツールであり、構造体とCSVファイルによるデータ管理を行う。機能ごとにモジュールを分離し、段階的に実装する。

## 2. 実装ステップ一覧

| ステップ | 内容                        | 関連モジュール     | 備考               |
|----------|-----------------------------|--------------------|--------------------|
| 1        | 空のウィンドウ作成              | main.c / ui.c      | GUI起動テスト       |
| 2        | 単語構造体の定義               | dictionary.h       | struct Word 作成   |
| 3        | 登録UIと入力フィールド作成        | ui.c               | 各入力欄/登録ボタン配置 |
| 4        | 単語登録ロジック実装             | dictionary.c       | 配列に追加処理       |
| 5        | 単語の保存/読込（CSV）          | fileio.c           | fopen / fprintf 等使用 |
| 6        | 検索処理の実装と表示              | dictionary.c / ui.c| 部分一致なども検討     |
| 7        | 削除処理とUI更新                 | dictionary.c / ui.c| 選択削除             |
| 8        | 一覧表示とタイプフィルター機能      | ui.c               | ComboBox活用        |
| 9        | クイズUIと出題ロジック             | quiz.c / ui.c      | ランダム出題・正誤判定   |
| 10       | 熟練度カウント機能                 | dictionary.c       | 解答履歴に応じて加算    |
| 11       | エラー処理とダイアログ表示対応       | 全体               | 上限超過・未入力など     |
| 12       | 結合テスト / テスト項目に基づく検証 | 全体               | テスト計画と照合       |

## 3. 使用予定ファイル一覧

- `main.c` : WinMain / メッセージループ  
- `ui.c` : 画面構築・イベントハンドラ  
- `dictionary.c` : 単語構造体管理・検索/削除  
- `fileio.c` : CSV保存/読込  
- `quiz.c` : クイズ問題生成・評価  
- `resource.h` : UI定義（ID管理）
