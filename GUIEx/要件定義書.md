# 単語辞書プログラム - 要件定義書 (Requirements Definition)

## 1. プロジェクト概要

C言語を用いて GUI に基づいた日本語単語辞書プログラムを開発する。日本語の単語とその意味を登録・検索・削除・一覧表示できる機能を提供し、外国人学習者の語彙習得を支援する。

## 2. 対象ユーザー

日本語を母語としない学習者（初級〜中級レベル）

## 3. 開発目的

- C言語と WinAPI を用いた GUI アプリケーション開発の実践
- 外国語学習を支援するツール開発
- GUI開発経験を積むための個人プロジェクト

## 4. 機能要件 (Functional Requirements)

| 番号  | 機能名       | 内容                                               |
|--------|------------|----------------------------------------------------|
| FR-01 | 単語の登録   | 日本語単語（漢字・かな・意味）を入力してファイルに保存 |
| FR-02 | 単語の検索   | 単語を検索して、詳細情報（読み・意味）を表示             |
| FR-03 | 単語の削除   | 登録済みの単語を削除                                 |
| FR-04 | 単語一覧表ㅇ | 単語リストを一覧表示（GUIリストビュー）                    |
| FR-05 | クイズ機能   | 単語意味または読みを見て正しい単語を当てる形式のテスト機能     |
| FR-06 | オプション保存 | ファイルへの保存・読み込みによる継続利用                     |

## 5. 非機能要件 (Non-Functional Requirements)
- GUIで動作する
- 単語を分かれて保存できる（構造体利用）
- 学習程度を示す視覚的UI要素（色分け、チェックボックス等）
- ソースコードは適切にモジュール分割されている（main / ui / data 等）
