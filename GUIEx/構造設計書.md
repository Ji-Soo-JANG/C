# 構造設計

## 1. データ構造
```
|構造体─────────────────────────┐
├──漢字      (char[])           │
├──カナ      (char[])           │                                       
├──意味      (char[])           │                                        
├──タイプ    (int)              │                
├──熟練度    (int)              │                
├──例文      (char[])           │
└──────────────────────────────┘
```

## 2. 保存方式
- 単語データは構造体の配列としてメモリ上に保持
- プログラム終了時または任意のタイミングでファイルに保存（CSV形式）
- 起動時にファイルから読み込むことで学習進捗を維持可能
- 将来的にはOrcaleやMongoDB等のDBMSへの移行も検討可能（クエリベースの検索やスケーラビリティ対応）

## 3. 構成図（モジュール）

```
+-------------+
|   main.c    | メイン処理・画面制御
+-------------+
      ↓
+-------------+
|  ui.c       | 入力UI・画面描画（WinAPI）
+-------------+
      ↓
+-------------+
|  dictionary.c | 単語管理（追加・検索・削除）
+-------------+
      ↓
+-------------+
|  fileio.c   | ファイル保存・読込
+-------------+
```

## 4. 処理フロー

```
[ユーザー操作] → [UI操作] → [dictionary処理] → [UI更新]
                             ↓
                      [fileio保存/読込（必要時）]
```

## 5. エラーハンドリング

- ファイル読込エラー → 「保存ファイルが見つかりません」などのダイアログ表示  
- 単語が見つからない → 「単語が登録されていません」  
- 配列上限 → 「登録数の上限に達しました」  

## 6. 使用ライブラリ・技術

- C言語標準ライブラリ（stdio.h, string.h, stdlib.h）  
- WinAPI（GUI実装：ウィンドウ生成、コントロール配置、メッセージ処理）  
- ファイル形式：CSV形式または独自形式（テキストベース）  
- 今後の拡張候補：Orcale / MongoDBなどのDBMS
