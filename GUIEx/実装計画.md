# 実装計画（Implementation Plan）

## 1. 実装方針

本アプリケーションは、C言語および WinAPI を用いて開発する日本語単語学習ツールである。
単語データは `struct Word` と CSV ファイルで管理し、機能ごとにモジュールを分割して段階的に実装する。

- UI 層：`ui.c`（画面描画・イベント処理）
- ロジック層：`dictionary.c`（単語管理）、`quiz.c`（クイズ出題ロジック）
- 永続化層：`fileio.c`（CSV 読み書き）

各ステップで「UI → ロジック → 保存」の流れを意識して実装していく。

## 3. 使用予定ファイル一覧

- `main.c`  
  - WinMain エントリポイント  
  - メッセージループ、`UI_OnCreate` / `UI_OnCommand` などの呼び出し

- `ui.c`  
  - 画面構築（ホーム画面、登録画面、一覧画面、クイズ画面）  
  - ボタン / Edit / ListView / クイズボタンなどのイベントハンドラ  
  - 画面切り替え（ホーム ↔ 登録 ↔ 一覧 ↔ クイズ）

- `dictionary.c`  
  - `struct Word` 配列の管理（追加 / 修正 / 削除 / 全件取得）  
  - `proficiency` カウンタ管理（正解・不正解に応じて増減）  
  - 初期化 (`dict_init`) / 終了 (`dict_shutdown`) 処理

- `fileio.c`  
  - CSV ファイルへの保存 / 読込  
  - 文字コード（UTF-8 / BOM）の扱い、エラー処理

- `quiz.c`（将来的に分離予定）  
  - クイズ問題の選択ロジック  
  - ランダムに単語を選択し、4択の選択肢インデックス配列を生成  
  - 正誤判定 API（UI から呼び出し）

- `resource.h`  
  - コントロール ID 定義（ボタン、ListView、メニューなど）
